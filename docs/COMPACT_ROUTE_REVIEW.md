# v4 짧은 동선 검토안

2026-10-22. 사용자가 팀원 영상과 비교한 뒤 요청한 **로컬 검토 후보**다. 관제 저장소와 `관제웹앱` 세션에는 반영·전달하지 않았다. 기존 v3의 코드, 재생 링크, 완성 자료는 보존한다.

[새 재생 화면](figures/route-plan-v4-review-20261022/replay.html) · [수치 원본](figures/route-plan-v4-review-20261022/evidence/result.json)

## 바뀐 동작

- 기본 방문 순서는 A → B → 인계. 주문에 필요한 적재대만 방문한다.
- 작업대 사이에는 Y=-0.90m의 짧은 연결 구간을 사용한다. 전진 출차, 90° 회전, 오른쪽 이동, 90° 회전, 후진 도킹으로 연결한다. 기존 진입의 별도 180° 정렬 회전과 큰 순환 우회를 제거했다.
- 하역 후 Y=-1.15m의 아래쪽 구간으로 왼쪽 복귀한다. 두 연결 구간의 중심 간격은 25cm다. 모든 이동이 분리된 차선에 갇히는 도로 규칙이 아니라, 진출입을 포함해 한 대씩 사용하는 후보 경로다.
- 좌하단 대기줄 좌표는 v3와 같다. 후열 (0.46, -1.375), 선두 (0.80, -1.375), 두 로봇 모두 +X 방향. 선두가 출발한 다음 후열이 앞으로 이동한다.
- 기본 대기 출발은 90° 회전 후 후진 S자 곡선으로 목표 적재대에 접근한다. 뒤쪽 바구니가 바닥 경계나 대기 중인 다른 로봇을 침범하지 않도록 검사했다. 실기에서 후진 구간의 관측·제어 수단을 확보했다는 뜻은 아니다.
- 공용 이동 허가는 한 대만 가진다. 다른 로봇의 모사 적재/하역은 병행할 수 있다. 실제 팔의 작업 영역은 추가 확인 대상이다.
- 인계 작업대는 먼저 하역한 로봇이 기본 대기에 완전히 복귀할 때까지 점유를 유지한다. 다음 로봇은 적재대에 정지한다. 단순한 정책인 만큼 불필요한 대기가 남을 수 있다.

## 같은 조건의 비교

두 주문 모두 A/B를 방문하고, 두 버전 모두 같은 방문 순서·단일 이동 허가·선두 대기줄을 적용했다. 속도 상한은 0.08m/s, 각속도 상한은 0.5rad/s다. 가속도·제동·실제 추종 오차는 포함하지 않는다. 적재 12초/회, 하역 45초/회는 인계 대기가 보이도록 정한 비교용 타이머다.

| 측정 대상 | v3 경로 재계산 | v4 후보 |
|---|---:|---:|
| A → B 이동 거리 | 3.469m | 1.388m |
| B → 인계 이동 거리 | 3.316m | 1.498m |
| A → 인계 이동 거리 | 2.800m | 2.098m |
| 두 로봇 전체 이동 거리 | 24.516m | 12.997m |
| 두 주문 완료 후 두 로봇 복귀 | 412.300초 | 280.275초 |

전체 이동 거리는 약 47.0%, 모사 완료 시간은 약 32.0% 줄었다. 거리에는 로봇 기준점의 이동만 포함되며 제자리 회전은 0m다. 시간에는 회전 시간이 포함된다. **실물 처리량 개선 실적이 아니다.** 기존 v3 영상의 191.05초는 각 로봇이 적재대 한 곳만 방문하고 동시 이동을 허용한 별도 예제이므로 직접 비교하지 않는다.

## 검증한 범위

- 후보 경로 9개: 대기줄 전진 1, 대기→작업대 3, 작업대 사이 3, 인계→대기 선두/후열 2.
- 바구니를 포함한 외곽에 각 2cm를 확장하고 경계·칸막이·가정한 중앙 선반과의 연속 이동 구간을 보수적으로 검사했다.
- 대기 후열이 있을 때 선두 출발, 선두가 있을 때 후열 복귀, 선두가 점유된 상태의 후열 전진 금지를 검사했다.
- A만/B만/A+B 주문의 두 로봇 조합 9가지를 검사했다. 충돌 없이 필요한 적재대와 인계를 방문하고 기본 대기로 복귀한다.
- 이동 중 오래된 관측을 주입하는 예제는 두 로봇을 정지시키고 출발/목표 작업대와 이동 허가의 점유를 유지한다. 실제 관측 입력은 없으며 즉시 정지는 물리적 제동 모사가 아니다.
- 기존 36개 시험과 새 9개 시험, 총 45개 자동시험 통과. 웹 재생·조작 확인은 별도 `evidence/ui-check.json`에 기록한다.

## 미구현·제한

- v4는 배포용 주행기나 Nav2 Route Server 그래프가 아니다. 기존 v3 모듈을 기본으로 쓰는 다른 도구도 자동으로 v4로 전환하지 않았다.
- 실제 카메라 마커 검출, 센서 기반 후진 제어, 정차 정확도 판정, OMX 실행, 실기/Isaac 바퀴 추종은 이번 후보 재생에 포함되지 않는다.
- 팔의 가동 영역, 실제 양옆 선반·고객 바구니, 지연·제동·위치 불확실성은 완전히 모델링되지 않았다. 2cm 확장은 측정된 추종 허용 오차가 아니다.
- A/B 반복 방문, B→A 역순 업무, 적재 중 취소 후 복귀, 무제한 주문·관제 재시작 복구는 검토 범위 밖이다. 지원하지 않는 역순 이동은 오류로 거부한다.
- 두 주문 묶음이 종료할 때까지의 검토용 실행이다. 지속 주문 처리와 장비 이동 소유권은 향후 관제 통합에서 다룬다.
