## 실행 근거와 해석

- `outputs/media-route-001`: Isaac에서 도로 v3의 계산된 자세를 배치하고 1,765프레임을 렌더했다. 기본 대기·교대 인계·이상 정지의 시각화이며 바퀴 동역학이나 센서 추종 결과가 아니다. 팔은 정적 장면이며 상품 이동을 실행하지 않는다.
- `outputs/media-wheel-002`: 실제 바퀴 속도 목표와 PhysX로 움직이는 기존 단일 Pinky 시험을 녹화했다. 600개 물리 스텝과 영상 300프레임이다. 촬영 전후 물리 시각·자세가 변하지 않는지 확인하여 녹화 때문에 추가 물리 스텝이 들어가지 않게 했다.
- 물리 시험은 전진 약 19.77cm, 후진 약 19.98cm, 회전 약 56.56°였고 높이·정지 변위·유한 값·바구니 접촉 필터 검사가 통과했다. 전체 도로·두 대의 물리 충돌·실물 정확도·센서 도킹을 검증한 것은 아니다.
- 영상 세 개 전체 디코딩 검사가 통과했다. 임시 headless Edge에서 재생·중간 시점 탐색을 확인했고 페이지 오류는 없었다. [갤러리 검사](../outputs/media-gallery-check/result.json).
- 기존 36개 자동시험은 그대로 통과했고, 원본 자산 18개 해시가 유지됐다. 설치·실물 연결·관제 저장소·Git 쓰기는 수행하지 않았다.

첫 렌더 미리보기는 저장된 `/Render` 제품과 활성 viewport 충돌로 종료했다. 새 stage에 `/World`만 참조하여 해결했다. 첫 물리 녹화는 Fabric 비활성 환경에 `update_fabric=True`를 요청해 실패했으며 활성 여부를 확인하는 방식으로 수정했다. 실패한 시도는 성공 자료 묶음에서 제외하고 원래 출력 폴더에 남겼다.
