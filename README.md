# Pinky OMX Sim-to-Real

Pinky Pro 2대와 OMX-AI 작업용 로봇팔 3대의 주문·적재·운반·고객별 하역을 검증하기 위한 개인 포트폴리오 프로젝트.

**현재 단계: 프로젝트 준비 및 상세 계획 작성. 구현·시뮬레이션 실행·실기 검증은 아직 하지 않았다.**

- [상세 계획과 단계별 완료 기준](PLAN.md)
- 작성 기준일: 2026-10-22, Asia/Seoul.
- 현재 승인 범위: 새 폴더, 로컬 Git 저장소, 준비 문서와 최초 커밋.
- 후속 설치·실행·구현·실기 시험·외부 저장소 생성과 push는 별도 계획 검토 및 승인 대상이다.

## 개발 방향

Isaac Sim에서 공간·물리·센서와 ROS 2 연동을 구성하고, Nav2 Route Server와 경로 추종기, 중앙 구간 예약 관제, 작업대 카메라 기반 바구니 도킹을 단계별로 검증한다. Isaac Lab과 추가 학습은 필요성이 확인된 이후 선택한다.

고정 도로는 우향·좌향 차로와 작업대별 진입·출차를 분리하는 후보를 기준으로 검토한다. 도면의 연결 구조는 실제 통과 가능한 궤적이나 충돌 방지 검증 결과가 아니다.

- 설치본·기존 프로젝트·팀 저장소를 승인 없이 수정하지 않는다.

- USD·mesh·영상·로그의 Git 보관 및 공개 범위는 라이선스와 크기를 확인한 뒤 정한다.
